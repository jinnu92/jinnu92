# Praveen Kumar

Senior Manager, Information Security. I lead AI red teaming and offensive security work out of Gurugram, India.

My work sits on two sides of the same problem. **Security for AI**: hardening LLM systems, agents and AI-driven applications against adversarial use. **Security with AI**: using LLMs and agentic harnesses to scale offensive testing beyond what a human team can cover by hand. Ten-plus years in offensive security, hands-on across web application, API, network and LLM/AI penetration testing.

## What I work on

- **AI red teaming** - prompt injection, tool and agent abuse, MCP attack surface, model and data exfiltration, guardrail bypass
- **Offensive security automation** - agentic harnesses for recon, exploitation, triage and reporting
- **Programme building** - vulnerability disclosure frameworks, red team gate models, assessment tooling built from scratch
